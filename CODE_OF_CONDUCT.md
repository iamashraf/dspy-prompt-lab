# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short, be respectful and assume good faith. Keep discussion about the work. We do not accept harassment of any kind.

To report a problem, open a private security advisory on the repository (Security tab, "Report a vulnerability") or contact the maintainer through their GitHub profile. The maintainer keeps reports confidential.
